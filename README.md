# Soutine Qwen Image Prompts

**Prompt library / studio landing:** [https://soutine.ai/qwen-image-2-1-prompts](https://soutine.ai/qwen-image-2-1-prompts)

This package is a thin reference client for the free **Soutine Qwen Image Prompts** collection on [Soutine AI](https://soutine.ai/). Browse and copy prompts on the site; generation runs in the Soutine workspace.

## Install

```bash
pip install soutine-qwen-prompts
```

## Usage

```python
import soutine_qwen_prompts as lib
print(lib.LANDING)       # canonical deep link
print(lib.open_landing())  # returns the URL to open
```
